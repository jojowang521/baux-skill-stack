# BAUX Skill Stack

**AI Skills for B2B Product Design**

面向 B 端产品设计工作流的 AI Skills 能力库，覆盖需求澄清、产品原型、需求规格、高保真设计、设计校验与设计交付。数据报告作为跨阶段能力收录。

## 快速开始

1. 点击上表下载对应 ZIP，解压后阅读 `SKILL.md`。
2. 保留解压目录内的 references、scripts、assets 等配套资源。
3. 按所用 AI 工具的 Skill 加载方式安装，并准备所需输入。
4. 用一个小任务确认依赖、工具识别和输出质量，再用于实际项目。

可将具体 Skill 的 ZIP 下载地址交给具备网络访问、本地文件写入和 Skill 加载能力的 AI 编程工具，要求其先检查依赖再协助安装。普通聊天中读取说明不代表安装完成。

```text
请安装这个 Skill：<该 Skill 的 ZIP 下载地址>
先检查当前工具的支持情况与依赖，保留完整资源，不覆盖已有同名内容。
完成后说明安装位置、加载方式和未满足的依赖；不能安装时请给出原因。
```

## 使用范围与验证

版本号 1.0.0 是整理版本，不代表所有工具与生产环境均已验证。以下记录对应具体检查范围，不外推为完整项目验证。

### Ant Design 设计顾问

适合已有 Ant Design 项目；完整业务分析与 PRD 由其他流程承接。

- 输入：页面需求、已有代码、React 与 antd 版本
- 输出：组件建议 / Token 配置 / React 示例 / 审查清单
- 环境与依赖：配置、语法可用性与独立工具端到端验证分开记录
- 验证范围：示例使用 antd 5.27.6；其他版本与目标项目需另行验证。
- 验证记录日期：2026-10-09

试用需求：

> 帮我检查这个 Ant Design 客户列表页，保留现有组件库，指出筛选、表格状态与主题使用的问题。

### B 端页面设计

沿用现有设计系统；不替代专业图表、AI 产品规划或平台专属 API 指导。

- 输入：业务场景、字段、状态、操作与已有设计系统
- 输出：HTML 原型 / 页面结构 / 交互说明 / 审查清单
- 环境与依赖：配置、语法可用性与独立工具端到端验证分开记录
- 验证范围：演示数据保存在页面内存；生产权限与后端持久化未验证。
- 验证记录日期：2026-10-09

试用需求：

> 根据这份客户管理需求，梳理列表、新增表单与详情页，标出未知业务规则，并生成连通的演示原型。

### 微信小程序设计

浏览器原型不等于原生 WXML/WXSS 工程，也不代表审核通过。

- 输入：页面需求、截图或代码、目标设备及基础库信息
- 输出：布局建议 / 设计审查 / HTML 原型
- 环境与依赖：配置、语法可用性与独立工具端到端验证分开记录
- 验证范围：原生配置、部分官方条款与真机适配仍待专项验证。
- 验证记录日期：2026-10-09

试用需求：

> 设计一个小程序工作台及申请表单，明确安全区与胶囊避让的假设，输出可预览页面和待验证项。

### ECharts 图表积木

聚焦图表模块；完整报告叙事与整站不在核心范围。

- 输入：数据、指标单位、展示目标和页面约定
- 输出：ECharts option / 图表 JSON / HTML 区块 / React 骨架
- 环境与依赖：配置、语法可用性与独立工具端到端验证分开记录
- 验证范围：HTML 通过 CDN 加载 ECharts 5.4.3；React 骨架需在项目中验证。
- 验证记录日期：2026-10-09

试用需求：

> 把这份月度销售数据做成趋势图和 KPI 卡片，保留原始单位，未知值不要补零，输出可嵌入页面的 HTML 区块。

### Product Icons

包内 3D 图标用于工作台快捷入口；不替代工具栏 UI 图标或完整项目工具链。

- 输入：业务对象或动作、展示区域、目标风格
- 输出：资产候选 / 语义映射 / 引用建议 / 图标演示
- 环境与依赖：配置、语法可用性与独立工具端到端验证分开记录
- 验证范围：13 条原有映射保留；home 背景、资产许可和项目接入待完善。
- 验证记录日期：2026-10-09

试用需求：

> 为客户、订单和报告三个工作台入口选择统一风格图标，列出业务语义、资产键及未确认的项目审批状态。

### BAUX AI Workspace

内置模式聚焦客户列表与侧栏助手；无真实模型、后端或完整采购系统。

- 输入：业务需求、已有原型、角色权限、字段与历史决策
- 输出：分析计划 / 交互原型 / 验证记录 / PRD 草稿
- 环境与依赖：配置、语法可用性与独立工具端到端验证分开记录
- 验证范围：演示使用虚构数据与本地规则；真实 AI、后端权限、采购流程未验证。
- 验证记录日期：2026-10-09

试用需求：

> 为客户列表增加 Copilot，支持所选客户上下文、来源核查和可撤销的跟进任务；用演示数据，并记录已验证与未覆盖的流程。

### B 端页面规则校验

覆盖 6 条业务规则与 4 条确定性视觉规则；不替代服务端授权测试、完整业务状态机或 B2B UX Review。需要页面契约适配。

- 输入：可运行的本地静态页面、场景 query、稳定选择器、业务约定和可选视觉基线
- 输出：JSON / HTML 规则报告、页面截图、重复性对比
- 环境与依赖：Node.js >=20.11、Playwright、Chromium；需本地文件与浏览器执行能力，跨工具待验证
- 验证范围：已验证动作可用性与报告退出码语义、脚手架生成和拒绝覆盖；未完成 Playwright 浏览器正反场景、三次重复及跨工具验证。
- 验证记录日期：2026-10-10

试用需求：

> 检查这个订单管理页面。先确认页面契约和业务规则是否适用，再检查无权限、停用记录、批量选择及删除失败场景；无法建立的场景标为未执行，输出证据报告，不修改页面。

### B 端业务数据报告

负责完整报告的分析与叙事；ECharts 图表积木负责嵌入式图表模块。渲染脚本不直接读取 Excel、不自动计算业务指标。

- 输入：CSV / Excel 或已整理数据、统计周期、指标口径、报告读者与分析目标
- 输出：报告 JSON / 内联 G2 的 HTML / 指标计算口径与分析说明
- 环境与依赖：Python 3.10+、浏览器；G2 随包内联。Excel 解析库按环境准备；AntV 文档连接器可选。
- 验证范围：5 项渲染回归测试通过；三套样例重新生成，销售 11 个图表浏览器渲染成功。经营/增长仅生成检查，样例业务结论未独立审计；工单/行为及跨工具流程待实测。
- 验证记录日期：2026-10-10

试用需求：

> 根据这份销售数据生成完整分析报告。先核对周期、单位、缺失值与指标分母，再计算 KPI、选择图表并给出有证据的发现；不能计算的指标标明原因，交付可离线 HTML 与计算口径。

### BAUX 用户体验地图

从访谈、观察记录、反馈、业务流程或已有体验地图，生成带来源依据的用户体验地图。材料不足时可创建明确标注的假设版；不直接设计业务系统 UI。

- 输入：研究材料 / 已有体验地图 / 结构化笔记 / 一句话需求，及角色、场景和旅程范围
- 输出：旅程 JSON、可离线 HTML、来源与证据状态、痛点和设计机会、校验报告
- 环境与依赖：Python 3 与浏览器，校验和渲染脚本仅使用 Python 标准库
- 验证范围：20 项回归测试通过；采购模拟示例的来源摘录校验通过并生成 7 阶段 HTML。模拟案例不代表真实用户研究；跨工具安装与真实项目效果待验证。
- 验证日期：2026-10-27
- 许可：上传包未声明独立许可，待作者补充；不推断 MIT 或其他授权。
- 版本：1.0.1 统一品牌命名，目录与 `SKILL.md` 名称改为 `baux-journey-map`，显示名称为「BAUX 用户体验地图」。功能及示例未变。
- 升级：旧名为 `research-to-journey-map`。使用新包替换旧安装目录，并将显式调用改为 `$baux-journey-map`；避免同时安装两个名称的副本。旧版下载文件保留，方便已有链接继续使用。

试用需求：

> 根据这份采购人员访谈梳理用户体验地图。先确认角色与旅程范围，再整理阶段、行为、接触点、情绪、痛点及机会点。每项结论保留来源；推断与设计假设单独标注，缺少的情绪数据不要补造。交付可离线 HTML、JSON 和校验结果。

### BAUX 产品体验评估报告

将产品资料、用户研究、体验记录、问题清单或已有报告整理为可追溯的体验评估与验收报告，包含产品框架、目标用户、完整体验地图、分类反馈与统计。支持材料不足的框架版和明确标注的模拟示例。

- 输入：产品及版本、角色与任务、研究/体验/测试材料、问题台账、评估范围及验收口径
- 输出：主数据与地图 JSON、单文件离线 HTML、校验结果与展示模型
- 环境：Python 3.10+ 标准库与现代浏览器；ECharts 和地图模板随包内置
- 边界：不替代测试执行，不将模拟材料当作真实验收；缺少依据时保留待补充或暂无法判定。
- 验证：28 项数据契约、17 项渲染、3 项主题检查通过；覆盖采购、客服、内容发布和材料不足样例。跨 AI 工具安装及真实产品效果待验证。
- 许可：原包未声明独立许可，内置 ECharts 保留 Apache 许可声明，其他资源条款待补充。
- 命名：包目录、Skill 名称及调用提示统一为 `baux-product-experience-report`；1.0.0 为本站首次收录版本。

试用需求：

> 根据这份产品资料和体验记录生成产品体验评估报告，包含目标用户、完整体验地图、问题分类与统计。每条问题保留证据来源，按明确的验收口径给出结论；未执行的测试与缺失材料如实标注，交付可离线 HTML 和结构化数据。
